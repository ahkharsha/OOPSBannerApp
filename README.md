# OOPS Banner Generator

A console utility application that renders the word "OOPS" as a large, stylized ASCII art banner. 

## Features
* Renders characters in a consistent 7-line height by 9-character width grid
* Efficient string building and console rendering
* Modular character mapping using standard Java collections
* Easily extensible architecture for adding new letters or custom words

## Tech Stack
* Java

## How to Run
1. Open your terminal or command prompt.
2. Navigate to the project folder.
3. Compile the application:
```bash
javac OOPSBannerApp.java
```

4. Run the application:
```bash
java OOPSBannerApp
```
