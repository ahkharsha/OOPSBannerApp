# OOPS Banner Application

A console-based application that displays an ASCII art banner for the text "OOPS". This project demonstrates basic Java output and string manipulation concepts.

## Features Implemented

### UC2: OOPS Banner Display
* Prints a stylized "OOPS" banner to the console using ASCII characters.
* Demonstrates string concatenation to form complex patterns line by line.
* Displays the banner in 7 lines with consistent spacing and alignment.

## Tech Stack
* Java

## How to Run
1. Open your terminal or command prompt.
2. Navigate to the project folder.
3. Compile all Java files:
```bash
javac *.java
```

4. Run the application:
```bash
java OOPSBannerApp
```
